# Elena TV theme

PatrikOS TV v0.2 introduces a lightweight child-friendly home screen for the TCL 32S5400AF reference device.

Goals:
- keep the launcher fast on ~1 GB RAM hardware;
- show only YouTube, Netflix and Disney+ on the home screen;
- keep System Settings one click away;
- show current time and date;
- use a static, soft child-friendly background with no animated wallpaper;
- retain D-pad-first navigation and zero telemetry.

The theme is intentionally implemented with Android XML drawables and native views so it does not add a large image or animation runtime cost.
